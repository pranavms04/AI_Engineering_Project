      Run it locally.

      You need Python 3.11 and Ollama. Nothing is uploaded anywhere, and no API key is needed.

      1. Get the code 
        git clone https://github.com/pranavms04/AI_Engineering_Project.git
cd AI_Engineering_Project
      2. Install 
        python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
      3. Get the local model 
        ollama pull llama3.2:3b
      4. Add your .pdf, .md or .txt files to data/sample_docs/, then index them 
        python -m scripts.build_index
      5. Start it (three terminals), then open localhost:8501 
        ollama serve
uvicorn app.api.main:app
streamlit run ui/streamlit_app.py

      It shows you where every answer came from, and it tells you when it doesn't know.
